# Personal Portfolio Website

## Project Overview

This is a responsive personal portfolio website built using
HTML, CSS and vanilla JavaScript.

The website introduces me, displays my skills and projects,
and provides contact information.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Features

1. Responsive navigation menu
2. About Me section
3. Skills section
4. Project cards generated using JavaScript
5. Project category filtering
6. Light and dark theme switcher
7. Theme preference saved using LocalStorage
8. Contact form validation
9. Live message character counter
10. Responsive mobile and desktop layout

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Alternatively, use VS Code Live Server.

No package installation or build step is required.

## Project Structure

my-portfolio/

- index.html
- css/style.css
- js/main.js
- README.md

## Known Limitations

- The contact form is a frontend demonstration.
- Messages are not sent or stored.
- Project links must be replaced with actual repository or demo URLs.
- Profile and social links must be customized.
